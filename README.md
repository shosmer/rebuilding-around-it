# Rebuilding around it

A short, audience-specific read of the [AI in Design 2026](https://stateofaidesign.com/) report by Designer Fund and Foundation Capital. Three stories, five beats each: what is going on, and why it matters to you.

Built with React 19, Vite, and [Astryx](https://astryx.atmeta.com/) with the Ledger theme layer (see `ledger-design-system/`). Deployed to GitHub Pages on every push to `main`.

```bash
npm install
npm run dev      # local dev server
npm run build    # production build to dist/
npm run astryx   # Astryx CLI (component docs, templates)
```

The figures are the report's own. The interpretation is Shannon Hosmer's.
